- Classifies **KL Grade** (0–4), **JSN severity**, and predicts **KOOS pain score** in a single forward pass
- Backbone: **ConvNeXt-Small** via `timm` with shared feature extraction

- Achieved **69% KL classification accuracy** with augmentation + weighted loss
